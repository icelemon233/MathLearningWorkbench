# 验证记录

以下区分本地自动化验收与生产环境基础检查。界面显示名为「数学学习工作台」，知识点可输入后保存为可选项；课后反馈使用固定开头和三个栏目。下文保留各次验收记录，真实模型生成的措辞仍需老师结合课堂情况核对。

## 中文界面与知识点选项（2026-10-22）

- 登录页、侧栏、移动菜单、页脚和浏览器标题改为中文；保留 AI、Word、PDF 等通用术语。侧栏标题限定宽度，长文字不会进入面包屑区域；未知英文服务错误显示中文提示。
- 输入知识点名称后按回车，或点击下拉中的保存选项，即在云端保存并选中。新知识点使用当前学生的年级和「未分类」章节，后续可在知识目录编辑；已有知识点不再因已关联而被隐藏。
- 选择已有掌握记录的知识点会带出原状态和备注，按选择时版本更新原记录。创建、删除和恢复选项均沿用原有 RLS，重复创建遇到唯一约束时读取已有项，删除与恢复检查版本。
- 「管理选项」和知识目录支持删除选项，实际操作为移出可选目录，保留掌握记录、课堂和固定月报。再次输入同年级的同名知识点会恢复原 ID；没有执行物理删除或新增数据库表。
- 18 项前端测试通过，包含 7 项知识点 API 行为测试和中文错误提示测试；另有 4 项公开构建边界测试。TypeScript 与生产构建通过。
- 7 组浏览器流程通过，使用合成记录及模拟接口。1440、1024、768、390、320px 下无标题重叠或页面横向溢出，覆盖已有项复用、新建持久化、取消/删除/恢复、刷新后重选、失败保留输入和重试、保存期间新增学生不改变记录归属，以及手机空目录创建和删除。没有运行时错误、组件警告或未拦截外网请求；唯一的 503 日志是刻意模拟的保存失败。
- 只读取云端表权限与约束元数据，确认知识点表启用 RLS，仅本人可读写，并具有防重复唯一约束。验收没有读写真实教学记录。

## 浏览器检查

浏览器测试使用本地网站和模拟请求，覆盖 Auth、REST、AI 接口与实时连接；没有调用真实 Supabase 或模型服务。Ant Design 改版重新检查了五个视图在 1440px、390px 和 320px 宽度下的布局，整页没有横向溢出；宽表格在卡片内部滚动。

本次 Ant Design 改版的两套浏览器操作验收共通过 16 组、240 次模拟请求，覆盖学生/知识目录/掌握情况/课堂的增改与归档恢复、必填及日期校验、并发版本冲突恢复、反馈编辑复制与重复保存、两种月报生成方式、固定快照导出及断网恢复。没有未拦截的外网请求、运行时异常或 Ant Design 弃用警告；错误路径测试中出现的资源加载失败对应刻意模拟的 502 和断网。页面与表单按需加载。

- 登录前不显示业务内容；缺少所有者授权时不读取业务表。
- 学生年级必填；课堂知识点版本在勾选时固定，刷新后不会漂移，冲突会阻止覆盖。
- 课后反馈可编辑和重复保存，保存反馈不会重复修改掌握情况。
- 学生、课堂、知识目录、掌握状态与月报筛选正常。
- 月报保存后只读；实际下载的 Word 和打印内容使用报告快照，不受后续档案或课堂修改影响。
- 已查看桌面及 320px、390px 手机截图；未发现页面横向溢出，长课堂表单和月报导出按钮可访问。
- 打印样式另以三页中文 PDF 检查，长段落跨页、页边距及文字完整性正常。Word 已验证原生 OOXML 结构；本地缺少文档渲染器，未完成 Word 独立视觉渲染。
